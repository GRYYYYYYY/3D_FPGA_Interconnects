\section{Introduction}
Architecture exploration changes segment lengths, switch patterns and the resources available for crossing dies. A router evaluating a candidate architecture needs estimates for reaching pins on each destination layer~\cite{lazagna,flatland,multidie}. A table built for a previous graph can be reused only when its construction inputs remain compatible. Otherwise the evaluator pays for another set of sample searches before negotiated routing begins.

Each sample records costs relative to its source. Equal delays can carry different congestion costs, so the order in which samples contribute to a cell matters. Searches from different groups can still overlap. Within a search, edges can propose updates together if the engine specifies when updates become visible and which pair survives.

STRICT overlaps native samples and restores their input order at reduction. ALT changes the update rule within a search. Its CPU and GPU backends apply the same rule. We qualify the resulting maps and independently check the routes that consume them.
