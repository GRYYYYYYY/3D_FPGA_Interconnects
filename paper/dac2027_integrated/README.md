This directory is a new manuscript; paper/dac2027 remains frozen.

Start with frontmatter.md (title, 99-word abstract, three contributions), main.pdf,
and claims_accel.json. The anonymous manuscript is main.tex; tables and figures
are generated by generate.py. data_bindings.json pins all consumed source JSONs.
The generator imports the existing CPU summary function and extracts the frozen
R6.2 formatter without executing its document-writing side effects. It reuses
R6.2 ALT content in the main text rather than inputting its standalone document.

Run in a Python environment with numpy, matplotlib and PyMuPDF:

    python build.py --tectonic /path/to/tectonic

This regenerates statistics/plots, validates frozen data and semantic scope,
builds the IEEEtran candidate, checks actual 6+1 page limits, embedded fonts,
anonymity, references and overflow, and compiles the source ZIP in a clean temp
directory. Tectonic 0.17.0 was used; its first run may fetch TeX dependencies.
Original tool provenance is in paper/dac2027/tools/provenance.json on the working
server. No GPU or FPGA tools are required. See BUILD.txt for typesetting only.

submission_source.zip contains anonymous typesetting sources and precomputed
figures/tables. It intentionally excludes internal claim ledgers containing
server provenance. The full regeneration scripts and frozen data remain in the
repository. The checker generates previews; visual_review.json separately
records actual page inspection and does not confuse preview creation with review.

Semantics: STRICT has the stated conditional wire-map equivalence; ALT has only
measured same-input CPU/CUDA sample/map agreement and case-specific route/QoR
qualification. Route SHA equality is not claimed. FPGA superiority and board
measurement remain false. LSTM is an ALT-tuning holdout in the same architecture
family, previously used by the CPU project. No new performance runs are made.

The final revision corrects the temporal LSTM holdout description and separates
native RRGraphView (STRICT) from exported CSR (ALT) in Section III-A/Fig. 1.
The existing full-BNN offline wave/edge counts and the independent eight-core
same-executable Flat control are recomputed from frozen raw logs/rows. They are
prose-only additions; the original performance tables and plotted observations
are unchanged. The new claims retain cohort/input/binary and timing boundaries.
LaZagna now cites ICCAD 2025, DOI 10.1109/ICCAD66269.2025.11240893.

The Content Generated by AI section discloses substantive text, code and diagram/
statistics script generation. ai_usage_evidence.json binds exact recorded model
identifiers to retained local session events; no public model-name mapping is
guessed. AUTHOR_CHECKS.md separately lists unresolved history and human review
items. Passing automated/visual checks does not attest completed author review.
