# Mechanism evidence manuscript

Start with main.pdf, the anonymous submission_source.zip and CHANGES_FROM_AUTHOR_REVIEW.md. The complete paper build runs build.py with Tectonic 0.16.0 and the original TeX bundle. recompute_mechanism.py reproduces the service-time table and Amdahl estimates from stored evidence. The ZIP contains the final TeX, referenced generated tables, TikZ figures and bibliography. review/checks.json records the independent clean rebuild.

CLAIM_EVIDENCE_MATRIX.csv links claims to their inputs. AUTHOR_REVIEW.md lists the remaining author decisions. paper_freeze.json binds the artifacts.
