\section{Scope and Limitations}
The experiments support scheduling benefits on frozen layered routing graphs and native CPU/GPU acceleration with explicit timing boundaries. STRICT equivalence is conditional on its stated ordering and numeric domain. ALT qualification covers tested inputs and routes, not arbitrary graphs, all seeds or a universal QoR bound. LSTM is a same-family tuning holdout; repeated timings do not enlarge the architecture population. Shared instances and three-process dispersion limit claims about small differences.

The FPGA study demonstrates finite connected behavior and executed-case RTL/model agreement. It does not establish formal equivalence, synthesized functional equivalence, board operation or measured memory service. External memory, shell integration and physical timing remain separate obligations. The retained routing failures diagnose these particular configurations, not the impossibility of FPGA acceleration. GPU performance is a strong reference, not a condition for reporting a qualified CPU comparison.
