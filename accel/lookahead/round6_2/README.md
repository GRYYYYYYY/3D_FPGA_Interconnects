# R6.2 evidence closeout

This directory contains read-only RR-graph and metadata observers. It does not
change the frozen ALT or STRICT algorithms. The metadata ABI observer exits86
before search; that expected stop is not a routing qualification or timing row.

The fixed base is e68ff9584324deb3de808815c0bc7f35ac3fed23. Existing R6.1 native
ELF and original-format CPU/CUDA libraries are reused. Their hashes, the fixed
inputs, process affinity, exact commands and effective algorithm environments
are recorded in the R6.2 result directory.

The scripts named la_accel_round6_2_* separate these steps:

- audit_graph: stream the entire immutable RR XML, count edges and degrees,
  retain the zero-fanin CHANZ sets, verify graph hashes.
- freeze: classify that set against exact channel-coordinate rules and freeze
  LSTM seed2 before new solver timing.
- build_profile: create an isolated diagnostic native/host-CUDA source overlay.
  One non-formal BNN run reports conversion/preparation children. The additional
  numeric-validation/target-count timer binding is frozen before this run.
- worker: one finite GPU-job owner; six Pipeline supplements, five held-out
  qualifications, conditional fifteen rotated formal processes, one profile,
  and a 900-second supervised optimization-decision window. No implicit retry.
- hardware: calculate primitive/port/service necessary conditions without
  synthesis or cache replay. Capacity-only examples are not implementation.
- stages/collect: use within-process partitions and paired raw samples.
- build_candidate: the one profile-selected ORIGINAL_DENSE_IPIN_FILL_V1 bridge
  change, with unchanged dense format and exact input/output qualification.
  The worker's legacy "reserve" command tag names this single candidate slot.
  Its four CPU/CUDA qualifications and twelve CUDA paired processes are separate
  from the frozen LSTM measurements; no optimized LSTM qualification is inferred.
- validate/report/paper/archive: gate claims, write a separate ALT appendix,
  retain compressed raw logs and bind large maps/routes/captures by hashes.

Original large artifacts stay in their managed result directories. The curated
evidence_snapshot is intended for git. Never add dependency symlinks (vendor,
data, build_cpu_slices), overwrite old experiments, or reuse an existing output
directory as a new run. A frozen plan is not permission to claim successful
qualification: check actual per-case/backend/shift/representation receipts.

E2 covers the whole native constructor. E1/service in the reused CUDA wrapper
ends before the final ABI output memcpy; E2 includes it. Capture/CPU validation
and the one diagnostic profile are excluded from formal timing. Historical
R6.1 and new-worker Pipeline times are not divided to claim same-host speedup.
Stock E2 uses the native log's 0.01-second precision; other E2 timers retain
nanosecond-format output. Timer formatting does not imply measurement accuracy.
